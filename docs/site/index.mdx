## The pipeline

The four workstreams are one pipeline, not four projects:

**detect the platform → model it → measure against the model → trace execution → visualize the result**

The attribute schema is the contract that joins them. A bandwidth number without
the working-set size and the last-level cache it was measured against is not a
result; a schedule animation without the fabric geometry is a cartoon. Changes
to the schema ripple through every downstream stage, so it is the part of the
repository worth designing carefully.
